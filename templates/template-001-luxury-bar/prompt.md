# Luxury Bar — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「夜間沉浸式訂位酒吧」為目標，用全螢幕光影、菜單板、活動節目表與浮動訂位列組成的完整 12 頁網站。

## 1. 樣板一句話定位
「黑金低光源的台北酒吧，讓人願意慢下來喝一杯。」

## 2. 適合產業
- 高級酒吧 / 餐酒館 / 威士忌吧
- 爵士俱樂部、夜晚會所
- 包廂型餐飲空間

## 3. 不適合產業
- 強調明亮活潑的親子餐廳
- 電商型商品零售
- 需要大量表單與功能的教育平台

## 4. 視覺方向
- 全畫面黑金低光源，金色僅做點綴，不超過 8% 面積。
- 照片僅保留中等明度，避免大面積亮色破壞夜色氛圍。
- 以燈箱、燭光、鏡面反射與玻璃杯微光營造「低亮度質感」。

## 5. 色彩策略
- 背景：`#0b0a08`（深黑帶暖底）
- 次背景：`#121009`
- 主色金：`#d4af5a`
- 高光金：`#f3dfa8`（僅用於標題與 hover）
- 文字：`#f4efe4`、輔助文字 `#b3a78c`
- 規則：所有文字與背景對比度 ≥ 7:1，金色只用於標題、按鈕與裝飾線條，不用於長段文字。

## 6. 版型策略
- Hero 為全螢幕底部對齊標題 + 半透明漸層，不做 50/50 切塊。
- 首頁節奏：Hero → 浮動訂位條 → 品牌故事 split → 招牌酒單三欄 → 空間寬幅 → 活動卡片 → 評價語錄 → CTA。
- 內頁維持左側窄欄標題 + 右側大內容，保持編輯感。

## 7. Hero Pattern
`fullscreen-atmosphere-hero` — 背景圖 55% 亮度、底部漸層至純黑、標題左對齊底部、兩個 CTA 按鈕。

## 8. Navigation Pattern
`top-navigation-mobile-drawer` — 桌面橫向選單 + 金色底線 hover；手機漢堡位於最右側，展開為全寬下拉，連結為 16px 白色文字（深底背景）。

## 9. Content Rhythm
`visual-story-menu-event-booking` — 視覺敘事 → 菜單 → 活動 → 訂位 CTA，形成「看 → 想要 → 預訂」節奏。

## 10. 圖片風格要求
- 光線昏暗、對比強烈、色彩偏暖金。
- 可接受：調酒師手部、琥珀色酒液、爵士演出剪影、木質紋理。
- 禁止：白天明亮照片、過度擺拍的食物平鋪、自拍或閃光燈人像。

## 11. 圖片數量要求
- Hero 1 張 + 服務/菜單 6 張 + 空間/作品 9 張 + Blog 4 張 + 聯絡地圖 1 張 + 品牌細節 2 張 + 預覽 1 張 = 24+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 沉浸首頁、即時訂位條、空間與活動預告 |
| about | 品牌故事、里程碑、調酒師團隊 |
| services | 完整酒單 + 主廚小食表 + 包廂品飲 |
| service-detail | 招牌調飲單品拆解與風味說明 |
| portfolio | 空間光影紀實 gallery |
| reviews | 酒客評價 + 媒體報導 |
| faq | 消費規範、Dress Code、包廂規則 |
| booking | 線上即時訂位表單 |
| process | 訂位 → 入場 → 開杯 → 離席四步 |
| blog | 調酒工藝、爵士歌單、風土筆記 |
| blog-detail | 深度長文 + Article Schema |
| contact | 地址、地圖、包場合作表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「台北大安酒吧」「黑金酒吧」「威士忌吧」「爵士酒吧訂位」
- 長尾：「台北夜間俱樂部推薦」「大安區包廂酒吧」「雪莉桶調酒」
- Title 格式：`主關鍵字 | NOIR 1888`
- Description 130–150 字，含位置 + 特色 + CTA。

## 14. CTA 策略
- 首頁 Hero：雙按鈕「立即訂位 / 瀏覽酒單」
- 浮動訂位條：日期+時間+人數+姓名，一鍵送出
- 內頁 CTA：酒單 → 訂位，空間 → 訂位，活動 → 保留席
- 顏色：金色底黑色字，hover 反色加亮

## 15. RWD 規則
- 桌面：3 欄卡片、雙欄 split、三欄評價
- 平板：全部降為 2 欄或單欄
- 手機：單欄、表單欄位堆疊、漢堡選單全寬展開
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 NOIR 1888、電話、地址、LINE ID、酒名與價格、活動日期、圖片 URL、Google Map 連結、評價內容、部落格文章。

## 17. 禁止事項
- 不允許出現白底段落或亮色大區塊。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許金色文字放在金色背景上，或深灰文字放在深黑背景上。
- 不允許在 Hero 放滿版 Logo，文字必須底部對齊。
- 禁止使用英文選單或中英混排（品牌名與專有名詞除外）。
