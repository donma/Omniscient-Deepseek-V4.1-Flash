# Cyber Security — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「企業資安信任」為目標，用資料儀表板、指標卡、案例編排與 SLA 表組成的完整 12 頁網站。

## 1. 樣板一句話定位
「讓資安從黑箱變成可量化的企業基礎建設。」

## 2. 適合產業
- 資訊安全顧問公司
- SOC / MDR 服務商
- 企業級 IT 服務商

## 3. 不適合產業
- 消費型零售品牌
- 餐飲 / 美業 / 個人工作室
- 需要大量視覺敘事的創意產業

## 4. 視覺方向
- 深藍黑底 + 科技網格背景 + 青藍高亮。
- 資料儀表板、終端機文字、指標卡建立「專業可量化」的視覺語言。
- 圖片以機房、工程師、儀表板、抽象網路為主，避免人物大特寫。

## 5. 色彩策略
- 背景：`#0a0f1a`（深藍黑）
- 次背景：`#0d1420`
- 面板：`#111a2a`
- 邊線：`#1e2c44`
- 主色藍：`#4aa8ff`
- 輔色青：`#5ff2d0`
- 文字：`#e8eef7`、輔助 `#8b9ab0`
- 規則：文字與背景對比度 ≥ 7:1，青藍只用於強調與數據，不用於長段文字。

## 6. 版型策略
- Hero 為左文右 console 儀表板，右側顯示即時安全狀態模擬。
- 首頁節奏：Hero → 信任指標 → 四大服務卡 → 案例雙欄 → 威脅摘要面板 → CTA。
- 內頁維持「標題區 + 資料面板 / 表格 / 卡片」的資料導向節奏。

## 7. Hero Pattern
`data-console-hero` — 左側大標題與 CTA，右側終端機風格的安全狀態模擬面板，背景為低透明度科技網格。

## 8. Navigation Pattern
`split-header-cta-right` — 桌面橫向選單 + 右側 CTA 按鈕（預約評估），手機漢堡位於最右側，展開為全寬下拉。

## 9. Content Rhythm
`metrics-grid-threat-feed` — 指標 → 服務 → 案例 → 情資摘要 → CTA，建立「可量化信任」的敘事節奏。

## 10. 圖片風格要求
- 色調偏冷、高對比、帶藍青光源。
- 可接受：機房、網路線材、工程師操作螢幕、抽象資料流、城市夜景。
- 禁止：明亮生活照、人物自拍、過度裝飾的辦公室擺拍。

## 11. 圖片數量要求
- Hero 1 張 + 服務/解決方案 6 張 + 案例 4 張 + Blog 4 張 + 團隊 4 張 + 預覽 1 張 = 20+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 信任建立首頁（指標 + 案例 + 情資摘要） |
| about | 創立背景、使命、認證與團隊 |
| services | 四大服務總覽與比較 |
| service-detail | MDR 服務範圍、SLA、技術堆疊 |
| portfolio | 產業案例列表（匿名化） |
| reviews | 客戶評價卡片牆 |
| faq | 導入時程、保密、費用、支援範圍 |
| booking | 免費資安評估預約表單 |
| process | 評估 → 設計 → 部署 → 營運四步 |
| blog | 威脅情資與專欄列表 |
| blog-detail | 深度威脅分析長文 |
| contact | 辦公室資訊與商務合作表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「企業資安」「MDR 託管偵測」「滲透測試」「零信任導入」
- 長尾：「台灣資安顧問公司」「ISO 27001 輔導」「SOC 外包」
- Title 格式：`服務名 | AEGIS SEC`
- Description 130–150 字，含服務範圍 + 優勢 + CTA。

## 14. CTA 策略
- 首頁 Hero：雙按鈕「預約資安評估 / 瀏覽解決方案」
- 導覽列右側常駐「聯絡我們」CTA
- 內頁 CTA：案例 → 預約評估，服務詳情 → 技術評估
- 顏色：藍底黑字，hover 轉青色

## 15. RWD 規則
- 桌面：4 欄指標、3 欄服務、2 欄案例
- 平板：降為 2 欄
- 手機：單欄、console 面板縮為全寬、漢堡選單全寬展開
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 AEGIS SEC、電話、地址、Email、服務名稱、案例描述、指標數字、圖片 URL、文章內容。

## 17. 禁止事項
- 不允許出現白底段落或亮色大區塊。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許深灰文字放在深藍背景上，或青藍文字放在青藍背景上。
- 不允許 Hero 右側 console 顯示真實客戶資料或敏感資訊。
- 禁止使用英文選單或中英混排（品牌名與專有名詞除外）。
