# Fashion Boutique — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「精品服飾 Lookbook」為目標，用大片留白、跨頁編排、單品拆解與預約試穿組成的完整 12 頁網站。

## 1. 樣板一句話定位
「以黑白灰為語言，呈現衣服在時間裡的輪廓。」

## 2. 適合產業
- 高級獨立時裝品牌 / 設計師品牌
- 精品服飾選品店
- 高級手工訂製服工坊

## 3. 不適合產業
- 大眾平價電商
- 促銷折扣型服飾店
- 科技 / 醫療 / 餐飲

## 4. 視覺方向
- 黑白灰極簡風格，照片帶 30% 灰階，強化線條與光影。
- 大片留白、襯線字體、編輯式排版，營造時裝雜誌感。
- 圖片以全身肖像、材質特寫、剪裁細節為主。

## 5. 色彩策略
- 背景：`#0f0f0f`（深黑灰）
- 次背景：`#151515`
- 面板：`#1a1a1a`
- 邊線：`#2c2c2c`
- 主色米灰：`#d8cfc2`
- 高光白：`#f2f0eb`
- 文字：`#f2f0eb`、輔助 `#a39e96`
- 規則：文字與背景對比度 ≥ 7:1，米灰色用於強調，避免大面積高彩度色彩。

## 6. 版型策略
- Hero 為全螢幕底部對齊大標題 + Volume 期數標記。
- 首頁節奏：Hero → 跨頁 Lookbook → 系列三欄 → 品牌哲學雙欄 → 活動卡片 → 媒體評價 → 試穿 CTA。
- 內頁維持時裝雜誌的「留白 + 大圖 + 細節文字」節奏。

## 7. Hero Pattern
`editorial-cover-hero` — 全螢幕雜誌封面感，期數文字、大字襯線標題、副標與雙 CTA。

## 8. Navigation Pattern
`minimal-top-mobile-overlay` — 極簡頂部橫向選單，手機漢堡全寬展開。

## 9. Content Rhythm
`lookbook-alternating-spread` — 跨頁大圖 → 細節拼貼 → 品牌理念 → 系列總覽 → 預約。

## 10. 圖片風格要求
- 色調偏冷、高對比、黑白灰為主。
- 可接受：模特兒全身肖像、布料特寫、版型紙樣、工作室日常。
- 禁止：彩色明亮背景、笑容誇張的大頭照、喧鬧的街拍。

## 11. 圖片數量要求
- Hero 1 張 + Lookbook 8 張 + 系列 6 張 + Blog 4 張 + 團隊 3 張 + 預覽 1 張 = 23+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 雜誌封面式首頁、Lookbook 跨頁 |
| about | 品牌哲學、使命、三個堅持、團隊 |
| services | 當季系列、經典款、訂製服務 |
| service-detail | 單品拆解、材質規格、保養建議 |
| portfolio | 完整 Lookbook 圖片集 |
| reviews | 媒體報導與客戶回饋 |
| faq | 訂製、退換貨、保養常見問題 |
| booking | 預約一對一試穿表單 |
| process | 購物與訂製四步驟流程 |
| blog | 風格誌（剪裁、材質、慢時尚專題） |
| blog-detail | 剪裁長文深度解析 |
| contact | 門市地址、營業時間、洽詢表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「精品服飾選品店」「台北設計師大衣」「黑白灰極簡穿搭」「高級服裝訂製」
- 長尾：「喀什米爾針織推薦」「義大利羊毛大衣剪裁」「慢時尚品牌」
- Title 格式：`頁面名 | MAISON ÉCLAT`
- Description 130–150 字，強調剪裁、材質與預約試穿。

## 14. CTA 策略
- 首頁 Hero：「瀏覽系列 / 預約試穿」
- 系列頁：「預約試穿 / 查看詳情」
- 顏色：米灰底黑字，hover 反白

## 15. RWD 規則
- 桌面：2 欄跨頁、3 欄系列、雙欄編輯
- 平板：降為 1 欄或 2 欄
- 手機：單欄、圖片全寬、漢堡選單展開
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 MAISON ÉCLAT、電話、地址、系列名稱、商品價格、圖片 URL、文章內容。

## 17. 禁止事項
- 不允許出現亮彩背景或高彩度按鈕。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許文字對比度低於 7:1。
- 禁止使用英文選單（品牌名與專有名詞除外）。

- 與 T016 Flower Wedding：T016 為淺色米白花藝，本樣板為深色黑白灰時裝 Lookbook。
