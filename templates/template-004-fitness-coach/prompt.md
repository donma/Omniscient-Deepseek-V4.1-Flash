# Fitness Coach — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「成果與信任」為核心，用左右 Split Hero、數據牆、成果對比與方案車道組成的完整 12 頁網站。

## 1. 樣板一句話定位
「不練給別人看，只練出你要的身體。」

## 2. 適合產業
- 私人健身教練 / 健身工作室
- 體態雕塑與體能訓練中心
- 運動表現訓練機構

## 3. 不適合產業
- 大型連鎖健身房（需要更複雜的課程系統）
- 美容 SPA（氣質不同）
- 醫療復健（需更嚴謹的醫療語言）

## 4. 視覺方向
- 深色高對比、粗體字、紅色強調與萊姆綠點綴。
- 大量學員訓練照、器材特寫與成果海報。
- 版面節奏明快，彷彿健身房的重低音節奏。

## 5. 色彩策略
- 背景：`#101010`
- 次背景：`#161616`
- 面板：`#1c1c1c`
- 主色紅：`#e63946`（強調與行動）
- 輔色萊姆：`#c7f464`（數據與成功）
- 文字：`#f5f5f5`、輔助 `#9d9d9d`
- 規則：文字對比 ≥ 7:1，紅色只用於標題或按鈕，不用於長段文字。

## 6. 版型策略
- Split Hero：左文右圖，左側放標題、證照與數據，右側放訓練照。
- 首頁節奏：Split Hero → 體驗課條 → 數據牆 → 成果格 → 方案車道 → 教練 → CTA。
- 內頁維持「數據 + 卡片 + 車道」的力量感節奏。

## 7. Hero Pattern
`split-coach-credential` — 左右分割，左文右圖，證照與數字在文字側。

## 8. Navigation Pattern
`bold-top-bar` — 粗體黑底導覽，紅色底線 hover，右側萊姆 CTA 按鈕。

## 9. Content Rhythm
`program-proof-transform` — 先證明成果，再談方案，最後引導預約。

## 10. 圖片風格要求
- 高對比、深色調、汗水與力量感。
- 可接受：槓鈴深蹲、壺鈴、跑步機、教練指導、器材特寫。
- 禁止：明亮休閒的運動照、時尚雜誌風、健康食品擺拍。

## 11. 圖片數量要求
- Hero 1 張 + 成果 6 張 + 教練 3 張 + 空間 3 張 + Blog 4 張 + 預覽 1 張 = 18+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 信任與成果首頁 |
| about | 教練理念、資歷、空間 |
| services | 四種方案與小班課表 |
| service-detail | 12 週方案週期拆解 |
| portfolio | 學員成果展示 |
| reviews | 學員評價 |
| faq | 課程、費用、取消、身體狀況 |
| booking | 體驗課預約表單 |
| process | 訓練四步與每週節奏 |
| blog | 訓練誌（技術、恢復、課表） |
| blog-detail | 深蹲技術深度文 |
| contact | 工作室資訊與洽詢表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「台北私人教練」「大安健身教練」「一對一健身」「體態雕塑」
- 長尾：「產後核心訓練」「初學者健身教練推薦」「半馬訓練教練」
- Title 格式：`主題 | IRONEDGE`
- Description 130–150 字，強調證照、成果與體驗課。

## 14. CTA 策略
- 首頁：體驗課條 + Hero 雙按鈕
- 內頁：方案 → 預約諮詢，成果 → 體驗課
- 顏色：紅色或萊姆綠底黑字，hover 反色

## 15. RWD 規則
- 桌面：Split Hero、4 欄數據、3 欄成果與教練
- 平板：降為 2 欄，Hero 改為上下堆疊
- 手機：單欄、方案車道改為直列、漢堡選單
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 IRONEDGE、教練名、方案與價格、成果數據、電話、地址、圖片 URL、文章。

## 17. 禁止事項
- 不允許出現白底段落或亮色大區塊。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許深灰字放在深黑背景上，或紅字放在紅底上。
- 不允許誇大不實的成果承諾（如「保證瘦身 X 公斤」）。
- 禁止使用英文選單（品牌名與專有名詞除外）。

- 與 T002 Cyber Security：T002 為藍色科技儀表板，本樣板為紅色力量與運動成果。
