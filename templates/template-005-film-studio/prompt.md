# Film Studio — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「影像敘事與電影感」為目標，用劇照 Masonry、片頭黑條、導演視角與專案諮詢組成的完整 12 頁網站。

## 1. 樣板一句話定位
「讓每一幀，都有它的理由。」

## 2. 適合產業
- 影像製作工作室 / 廣告片廠
- 企業品牌影片製作
- 紀錄片與活動影像團隊

## 3. 不適合產業
- 電商商品導向（需更高頻率更新）
- 資訊量大的教育平台
- 醫療 / 金融 / 政府網站

## 4. 視覺方向
- 黑色背景、紅色強調、等寬字體與膠片感細節。
- 照片以拍攝現場、調色工作間、器材與劇照為主，帶灰階與對比。
- 版面節奏如同片頭黑條 → 正片 → 片尾字幕的電影結構。

## 5. 色彩策略
- 背景：`#050505`
- 次背景：`#0a0a0a`
- 面板：`#101010`
- 邊線：`#242424`
- 主色紅：`#d7263d`（強調與行動）
- 輔色琥珀：`#e0a458`（期數、日期、時間標記）
- 文字：`#ececec`、輔助 `#8f8f8f`
- 規則：文字對比 ≥ 7:1，紅色只用於強調與行動，不用於長段文字。

## 6. 版型策略
- Hero 為全螢幕黑底 + 背景劇照 + 片頭黑條上下條紋。
- 首頁節奏：Hero → 近期作品捲軸 → 作品牆 → 獲獎條 → 導演筆記 → 專案諮詢 CTA。
- 內頁維持「片場日誌」式的編輯節奏，分鏡、剪輯、後製皆有獨立版面。

## 7. Hero Pattern
`film-reel-hero` — 全螢幕黑底，背景為淡影劇照，上下有片頭黑條，標題置中。

## 8. Navigation Pattern
`top-nav-underline-active` — 頂部橫向選單，紅色底線 active 與 hover，手機漢堡全寬展開。

## 9. Content Rhythm
`masonry-reel-awards` — 作品牆 → 獲獎 → 導演視角 → 專案諮詢，建立「作品說話」的信任節奏。

## 10. 圖片風格要求
- 色調偏冷、高對比、帶灰階或底片感。
- 可接受：攝影機、剪輯室、燈光器材、拍攝現場、劇照、城市夜景。
- 禁止：明亮生活照、自拍、過度裝飾的辦公室擺拍。

## 11. 圖片數量要求
- Hero 1 張 + 作品牆 9 張 + 團隊 3 張 + 服務 4 張 + Blog 4 張 + 預覽 1 張 = 22+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 電影感首頁（片頭黑條 + 作品牆） |
| about | 工作室理念、團隊、里程碑 |
| services | 六種製作服務與報價區間 |
| service-detail | 品牌形象影片服務詳情 |
| portfolio | 完整作品牆（9 案） |
| reviews | 客戶評價卡片牆 |
| faq | 報價、時程、版權、修改常見問題 |
| booking | 專案諮詢預約表單 |
| process | 企劃 → 前置 → 拍攝 → 後製 → 交付 |
| blog | 幕後誌（企劃、後製、溝通、現場） |
| blog-detail | 腳本與分鏡深度文 |
| contact | 工作室資訊與專案洽詢表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「品牌影片製作」「廣告影片」「企業形象片」「紀錄片製作」
- 長尾：「台北影像製作工作室」「影片拍攝報價」「品牌影片腳本」
- Title 格式：`頁面名 | FRAMELAB STUDIO`
- Description 130–150 字，強調作品、團隊與專案諮詢。

## 14. CTA 策略
- 首頁 Hero：「預約專案諮詢 / 觀看作品集」
- 內頁：服務 → 預約諮詢，作品 → 聯絡我們
- 顏色：紅底白字，hover 加亮

## 15. RWD 規則
- 桌面：4 欄作品、3 欄團隊、雙欄編輯
- 平板：降為 2 欄
- 手機：單欄、作品牆改為 1 欄、漢堡選單
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 FRAMELAB、導演名、作品名稱、獲獎紀錄、報價區間、圖片 URL、文章內容。

## 17. 禁止事項
- 不允許出現白底段落或亮色大區塊。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許深灰字放在深黑背景上，或紅字放在紅底上。
- 不允許在作品牆使用會 403 / 404 的圖片。
- 禁止使用英文選單（品牌名與專有名詞除外）。

- 與 T001 Luxury Bar：T001 以「訂位轉換」為核心，本樣板以「作品展示與專案諮詢」為核心。
- 與 T011 Music Festival：同為深色活動感，但本樣板以「品牌影像製作」為主題，T011 以「活動購票」為主題。
