# AI SaaS — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「SaaS 產品功能敘事」為目標，用 Bento 模組格網、產品截圖區與免費試用流程組成的完整 12 頁網站。

## 1. 樣板一句話定位
「把團隊散落的知識，變成一問就答的記憶體。」

## 2. 適合產業
- AI 軟體 / SaaS 新創
- B2B 產品公司（協作、資料、AI 工具）
- 企業服務平台

## 3. 不適合產業
- 餐飲、美業、實體店面
- 大量商品電商
- 活動單頁

## 4. 視覺方向
- 深藍黑漸層 + 紫青漸層高光，營造「未來感但不冰冷」。
- Bento 模組格網把功能切成小塊，讓資訊密度感與呼吸感共存。
- 圖片以抽象科技、介面截圖、團隊協作為主。

## 5. 色彩策略
- 背景：`#08060f`（深紫黑）
- 次背景：`#0c0a16`
- 面板：`#131022`
- 主色漸層：`#7c6cf0 → #4dd0c7`
- 輔色粉：`#f472b6`
- 文字：`#eeeaff`、輔助 `#9b95b8`
- 規則：文字對比 ≥ 7:1，漸層只用於標題與強調，不用於長段文字。

## 6. 版型策略
- Hero 為左文右 Bento 模組格網，資訊密度高但層次分明。
- 首頁節奏：Hero Bento → 信任指標 → 功能模組 → 案例 Bento → CTA。
- 內頁維持「模組格網 + 表格 + 卡片」的 SaaS 節奏。

## 7. Hero Pattern
`bento-feature-hero` — 左側大標題與 CTA，右側 Bento 模組格網展示功能摘要。

## 8. Navigation Pattern
`pill-nav-center` — 置中膠囊式導覽 + 右側免費試用 CTA，手機漢堡全寬展開。

## 9. Content Rhythm
`bento-feature-flow` — 功能模組 → 案例 → 成效 → 試用，讓資訊一眼掃過也能深入。

## 10. 圖片風格要求
- 抽象科技、介面截圖、團隊協作、資料視覺化。
- 可接受：AI 介面、資料圖、辦公室協作、雲端架構示意。
- 禁止：生活照、人物自拍、明亮休閒風。

## 11. 圖片數量要求
- Hero 2 張 + 功能 6 張 + 案例 6 張 + Blog 4 張 + 團隊 3 張 + 預覽 1 張 = 22+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | Bento 首屏 + 信任指標 + 功能模組 + 案例 |
| about | 創立故事、產品哲學、團隊 |
| services | 六大功能模組與方案價格 |
| service-detail | 知識問答功能詳情 |
| portfolio | 客戶案例牆（6 案） |
| reviews | 客戶評價卡片牆 |
| faq | 試用、資安、資料、整合常見問題 |
| booking | 14 天免費試用表單 |
| process | 導入四階段與責任分工 |
| blog | 產品誌（AI 架構、產品設計、導入） |
| blog-detail | RAG 三道防線深度文 |
| contact | 業務、技術、媒體聯絡表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：「AI 知識管理」「團隊知識庫」「SaaS 協作工具」「AI 問答系統」
- 長尾：「14 天免費試用 SaaS」「Slack AI 整合」「企業知識平台」
- Title 格式：`功能名 | NEURA FLOW`
- Description 130–150 字，強調試用、整合與成效。

## 14. CTA 策略
- 首頁 Hero：「14 天免費試用 / 觀看產品功能」
- 導覽列右側常駐「免費試用」
- 內頁：功能 → 試用，案例 → 試用
- 顏色：漸層按鈕，hover 加亮

## 15. RWD 規則
- 桌面：4 欄 Bento、3 欄功能、3 欄案例
- 平板：降為 2 欄
- 手機：單欄、Bento 改為 1 欄、漢堡選單
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名 NEURA FLOW、產品功能名、價格、圖片 URL、文章內容、案例數據。

## 17. 禁止事項
- 不允許出現白底段落或亮色大區塊。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許漸層文字與漸層背景對比不足。
- 不允許使用「AI 很厲害」等空泛文案，必須具體功能與數據。
- 禁止使用英文選單（品牌名與專有名詞除外）。
