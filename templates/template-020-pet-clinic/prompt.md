# Pet Clinic — AI 樣板 Prompt

> **本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。**
> 它是以「柔和有機氣泡膠囊語言動物醫院官網：大圓角果凍卡片、Blob 遮罩照片、漂浮藥丸徽章、對話氣泡客評與 Fear-Free 無痛看診體驗。」為目標，用 Split Trust 專業信任型 版型、vet-care-split Hero 與獨特內容節奏組成的完整 12 頁網站。

## 1. 樣板一句話定位
柔和有機氣泡膠囊語言動物醫院官網：大圓角果凍卡片、Blob 遮罩照片、漂浮藥丸徽章、對話氣泡客評與 Fear-Free 無痛看診體驗。。

## 2. 適合產業
- 動物醫院
- 犬貓專科門診
- 寵物預防保健中心
- 相關產業與延伸品牌

## 3. 不適合產業
- 與本樣板視覺氣質不符的產業
- 需要複雜後端功能的系統

## 4. 視覺方向
- 白綠信任 色系，版面節奏為 care-team-visit-flow。
- 圖片風格需與產業氣質一致，禁止使用會 403/404 的圖片。

## 5. 色彩策略
- 背景與文字對比度 ≥ 7:1，強調色只用於標題、按鈕與裝飾。
- 淺色底用深色文字、深色底用淺色文字，不得相近。

## 6. 版型策略
- Hero 為 vet-care-split，導覽為 emergency-strip-top。
- 首頁節奏：Hero → 內容敘事 → 服務/商品 → 案例/作品 → 信任元素 → CTA。
- 內頁維持與首頁一致的視覺語言，不可變成普通卡片堆疊。

## 7. Hero Pattern
`vet-care-split` — 依樣板風格客製，非通用版式。

## 8. Navigation Pattern
`emergency-strip-top` — 桌面橫向選單 + 手機漢堡全寬展開。

## 9. Content Rhythm
`care-team-visit-flow` — 敘事節奏需與產業特性一致。

## 10. 圖片風格要求
- 與產業氣質一致，色調統一。
- 可接受：產業相關情境、工作場景、產品細節、人物互動。
- 禁止：來源不明、浮水印、與產業無關的圖片。

## 11. 圖片數量要求
- Hero 1 張 + 服務/商品 6 張 + 案例/作品 8 張 + Blog 4 張 + 聯絡/場域 2 張 + 品牌細節 2 張 + 預覽 1 張 = 24+ 張。

## 12. 12 頁內容定位
| 頁面 | 功能 |
|---|---|
| index | 首頁（vet-care-split + 核心敘事 + CTA） |
| about | 品牌故事、團隊、里程碑 |
| services | 服務/商品總覽與分類 |
| service-detail | 單一服務/商品深度說明 |
| portfolio | 作品/案例展示 |
| reviews | 客戶評價與媒體報導 |
| faq | 常見問題 |
| booking | 預約/訂位/報名表單 |
| process | 服務流程與注意事項 |
| blog | 產業專欄與內容行銷 |
| blog-detail | 深度文章內頁（Article Schema） |
| contact | 聯絡資訊與洽詢表單 |

## 13. SEO 關鍵字策略
- 核心關鍵字：產業 + 服務 + 地區
- Title 格式：`頁面名 | 品牌名`
- Description 130–150 字，含服務範圍 + 特色 + CTA。

## 14. CTA 策略
- 首頁 Hero：雙按鈕（主要 + 次要）
- 內頁：內容 → 預約/聯絡，案例 → 預約
- 顏色：主色底 + 對比色文字，hover 反色或加亮

## 15. RWD 規則
- 桌面：多欄排版、Split Hero、寬幅圖片
- 平板：降為 2 欄
- 手機：單欄、漢堡選單全寬展開
- 斷點：960px / 640px

## 16. 可替換內容
- 品牌名、電話、地址、Email、服務/商品名稱、價格、圖片 URL、文章內容。

## 17. 禁止事項
- 不允許出現白底段落（深色底樣板）或黑底段落（淺色底樣板）。
- 不允許使用「建置中」「Coming Soon」或空白頁。
- 不允許文字對比度低於 7:1。
- 禁止使用英文選單（品牌名與專有名詞除外）。

## 18. 與相似樣板的差異說明
重做亮點：彻底消滅難看的虛線護照格子，改以柔和有機氣泡（Blob 遮罩照片、漂浮藥丸卡、大圓角果凍卡、對話氣泡客評），溫柔感與療癒感滿分。
